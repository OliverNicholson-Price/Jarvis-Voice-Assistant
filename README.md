# Jarvis-Voice-Assistant
A simple voice assistant made in Python. Just drop this into your Python IDE, import the relevant libraries, and it should be good to go!
List of current available commands:
"What time is it?" - tells you the time
"Repeat what I say" - repeats what you tell it to
"Open website" - opens a requested website
"Open weather" - searches for the current weather
"Open music" - opens Spotify's website
"Clip that" - creates a clip using OBS (requires OBS WebSocket to be active)
More will be added when I can think of more things to add.
